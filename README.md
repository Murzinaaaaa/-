Я считаю эту практическую работу не самой простой так как я создала игровой трекер привычек на Flask с использованием SQLAlchemy и Flask-Login. Реализовала регистрацию и вход пользователей, создание привычек с наградами в очках, систему уровней, подсчёт стриков и систему достижений. Использовала составное уникальное ограничение, чтобы нельзя было отметить привычку дважды за один день, и атомарные транзакции для безопасного начисления очков.
