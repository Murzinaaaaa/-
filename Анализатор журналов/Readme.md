Как запустить и проверить
Установка зависимостей: pip install -r requirements.txt
Запуск анализа логов: python main.py logs_events_sample.log
Сохранение отчета в файл: python main.py logs_events_sample.log --format json --output report.json
Запуск тестов и покрытия: python -m pytest test_app.py --cov=app --cov-report=html:htmlcov -v
Что реализовано
- Построчное чтение большого файла (O(1) памяти по строкам).
- Валидация: 5 полей, ISO 8601 UTC, уровень из TRACE/DEBUG/INFO/WARN/ERROR, непустые поля.
- Фильтры (AND): --from, --to, --level, --source.
- Счётчики: всего/валидных/невалидных, событий после фильтрации, сводки по уровням/источникам, top-N кодов.
- Вывод в терминал + сохранение JSON/CSV через --format json|csv --output FILE.
- Повреждённые строки не останавливают обработку; выводятся номер и причина.
- Пустой файл - нулевая сводка; отсутствующий/каталог - ошибка с кодом 2.
- Детерминированный порядок сортировки: по убыванию счётчика, затем по имени.
